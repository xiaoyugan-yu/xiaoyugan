🔫 打枪游戏 (Shooter)

一个 3D 第一人称射击游戏，用 Ursina 引擎 + Python 开发。

📷 项目截图

无

🎮 玩法说明

  • WASD：移动
  • 空格：跳跃
  • 鼠标左键：射击
  • R：换弹
  • Q/E 或滚轮：切换武器
  • ESC：暂停

🔫 武器系统

  • Pistol：手枪，伤害 30，射速中等
  • Rifle：步枪，伤害 25，射速快
  • Shotgun：霰弹枪，伤害 20，射速慢

👾 敌人类型

  • Normal：普通敌人，速度血量均衡
  • Fast：快速敌人，速度快但血量低
  • Tank：坦克敌人，血厚但速度慢
  • Ranged：远程敌人，会远距离攻击

📝 开发心得

这是我用 Ursina 引擎做的第一个 3D 射击游戏。过程中学会了第一人称控制器、射线检测、波次系统和 UI 设计。未来打算添加更多武器、地图和 boss。
